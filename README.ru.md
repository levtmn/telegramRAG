# TelegramRAG

*На других языках: [English](README.md)*

Локальный поиск с ответами (**RAG**) по экспортам ваших групповых чатов Telegram. Задаёте вопрос
обычными словами — получаете ответ по реальным сообщениям, со ссылками на источники. Всё работает
на вашей машине, достаточно лёгкое даже для **Raspberry Pi 5**. Тяжёлый ML вынесен в облачные API —
ни локальной видеокарты, ни больших моделей не нужно.

Можно проиндексировать несколько чатов сразу. Поиск **гибридный**: векторы (смысл) + BM25 (точные
слова), результаты объединяются, переранжируются и отправляются в Claude, который пишет ответ
прямо в веб-интерфейсе.

---

## Что под капотом

| Слой | Инструмент |
|---|---|
| Векторная БД | **Qdrant** (встроенный, без сервера) |
| Эмбеддинги | **Cohere `embed-multilingual-v3.0`** — хорошо понимает живой русский, сленг, смесь языков |
| Ключевые слова | **BM25** — ловит точные имена, даты, номера |
| Объединение | **RRF** (Reciprocal Rank Fusion) |
| Переранжирование | **Cohere Rerank** |
| Ответ | **Claude (`claude-sonnet-4-6`)** |

---

## Как это работает

1. **Разбор** (`scripts/preprocess.py`) — читает `result.json`, склеивает сообщения в треды-беседы
   по ответам и паузам, режет на куски по ~80–600 токенов.
2. **Индексация** (`scripts/index.py`) — считает эмбеддинги через Cohere, строит индексы Qdrant и
   BM25. Эмбеддинги кешируются по каждому чату, поэтому повторная индексация — мгновенная.
3. **Запрос** — вектор + BM25 → объединение (RRF) → фильтр по дате → переранжирование → ответ Claude
   со ссылками на источники.

## Быстрый старт

```bash
git clone https://github.com/levtmn/telegramRAG.git
cd telegramRAG

pip install -r requirements.txt --break-system-packages

cp .env.example .env        # впишите COHERE_API_KEY и ANTHROPIC_API_KEY
```

Добавьте экспорт чата (Telegram Desktop → ⋮ → *Экспорт истории чата* → формат **JSON**):

```bash
mkdir -p telegram-mychat/origin
cp /путь/к/result.json telegram-mychat/origin/result.json
```

Индексация и запрос:

```bash
python3 scripts/preprocess.py
python3 scripts/index.py
python3 scripts/query.py "что писал Вася про машину"
```

> Первая индексация идёт долго (~50–60 мин на ~11 тыс. фрагментов) из-за лимитов бесплатного тарифа
> Cohere. Повторная — мгновенная за счёт кеша.

## Веб-интерфейс

```bash
python3 web/app.py        # http://localhost:8080
```

- **Проекты** — автоопределение чатов, индексация в один клик с прогресс-баром, загрузка архива
  (`.zip` / `.tar.gz`), редактируемые названия, диапазон дат по каждому чату.
- **Запросы** — фильтр по чату и датам; ответ Claude печатается в реальном времени, источники —
  свёрнутыми чипами.
- **История** — диалоги сохраняются в SQLite, можно вернуться к прошлой сессии, очистить или
  сохранить в PDF.

В репозитории **нет данных чатов** — добавляете свои. Папки `db/`, `bm25/`, `data/` и все
`telegram-*/` исключены из git.
